# Açaí Map Belém — Web Dashboard

Interactive dashboard for visualizing açaí establishments in Belém, Pará.

## Architecture

```
web/
├── index.html              # Main entry point
├── build_data.py           # Data pipeline: CSVs → dashboard_data.js
├── assets/
│   ├── logo.svg            # Full logo with text
│   ├── logo-mark.svg       # Symbol only
│   └── favicon.svg         # Browser favicon
├── css/
│   ├── variables.css       # CSS custom properties (design tokens)
│   ├── reset.css           # Minimal reset
│   ├── layout.css          # Header, hero, sections, grid
│   ├── components.css      # KPI cards, filter chips, detail panel
│   ├── map.css             # Leaflet overrides, tooltips, legend
│   ├── charts.css          # Chart containers
│   ├── tables.css          # Data table
│   └── responsive.css      # Breakpoints: 1400/1200/1024/768/480px
├── js/
│   ├── app.js              # Entry point, module orchestration
│   ├── state.js            # Central state + pub/sub dispatcher
│   ├── data.js             # Data access helpers (wraps window.ACAI_MAP_DATA)
│   ├── filters.js          # Filter UI: dropdowns, active chips
│   ├── kpis.js             # KPI card rendering with count-up animation
│   ├── map.js              # Leaflet map, markers, detail panel, mini-map
│   ├── charts.js           # 6 Chart.js charts (bar, doughnut, scatter)
│   ├── tables.js           # Sortable paginated table
│   ├── animations.js       # Canvas particle background
│   ├── interactions.js     # Navigation, keyboard, global search
│   └── utils.js            # fmt, debounce, haversine, countUp, etc.
└── data/
    └── dashboard_data.js   # Generated by build_data.py (gitignore-able)
```

## Generating the data

Run from the project root:

```bash
python web/build_data.py
```

This reads the four source CSVs and writes `web/data/dashboard_data.js` containing
`window.ACAI_MAP_DATA` with all 442 establishments, 1 766 occurrences, 60 queries
and 10 neighborhoods.

## Running locally

Any static file server works. Examples:

```bash
# Python (from web/ directory)
cd web && python -m http.server 8080

# Node (npx)
cd web && npx serve .

# VS Code Live Server
# Right-click index.html → Open with Live Server
```

Then open `http://localhost:8080`.

> **Note:** The dashboard uses ES modules (`type="module"`), so it must be served
> over HTTP/HTTPS — opening `index.html` directly with `file://` will fail due to
> CORS restrictions on module imports.

## Data sources

| File | Rows | Description |
|------|------|-------------|
| `data/powerbi/dim_estabelecimentos_pbi.csv` | 442 | Establishments with coordinates, ratings, density |
| `data/model/fact_ocorrencias_busca.csv` | 1 766 | Search occurrences per establishment |
| `data/model/dim_consultas.csv` | 60 | Query metadata |
| `data/model/dim_bairros.csv` | 10 | Neighborhood reference data |
